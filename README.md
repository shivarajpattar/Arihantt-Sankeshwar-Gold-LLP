# Arihant Sinkeshwar - Luxury Jewelry Brand

A premium Next.js application for Arihant Sinkeshwar, showcasing heritage and master craftsmanship.

## Tech Stack
- Next.js 14
- React
- Tailwind CSS
- Lucide Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
